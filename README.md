# Descargas de NICAPARTES

Acá vive el instalador del programa de escritorio de **NICAPARTES**, la tienda
de repuestos automotrices de Estelí, Nicaragua. El código del sistema es
privado; este repositorio solo guarda el archivo para que se pueda descargar
sin cuenta de GitHub.

## Descargar

**[Instalador para Windows (64 bits)](https://github.com/EleanFPC/nicapartes-descargas/releases/latest/download/NICAPARTES-Instalador.exe)**

Esa dirección apunta siempre a la última versión publicada.

## Al instalar

Windows va a mostrar el aviso **"Windows protegió tu PC"**. Es porque el
instalador no está firmado digitalmente, no porque tenga algo raro: tocá
**Más información** y después **Ejecutar de todos modos**.

## Cómo se publica

Lo compila un flujo de GitHub Actions en una máquina Windows, desde el
repositorio del sistema, y lo sube acá como Release. No se sube a mano.
